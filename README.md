Link to the deployed webpage: https://immersive-production.up.railway.app/ 

This is my first project in Three.js. I'm in the process of designing it for a VR viewing! 

This site guides the user through 4 distinct, mouse-interactive 3D environments (made almost entirely in Three.js with minimal blender work): 
Night Meadow, Koi Pond, Starlit Cosmos, and Fireside Glow. 

The scenes are actually used as animated backgrounds of a nature-awareness conference hosted in my university!
